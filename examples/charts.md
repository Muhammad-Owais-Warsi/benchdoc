## Bars

Horizontal bars scaled to the max. Top row highlighted, hover any row for its value.

```chart
[{"label": "terminal-agent / atlas-large", "value": 72}, {"label": "shell-solver / atlas-large", "value": 68}, {"label": "terminal-agent / atlas-medium", "value": 54}, {"label": "baseline / atlas-small", "value": 31}]
```

## Donut

Shares of a whole — pass/fail splits. Hover a segment or read the legend.

```donut
{"Pass": 34, "Fail": 13, "Partial": 3}
```

## Line

Reward over trials. Hover any dot for its exact value.

```line
[{"label": "t-01", "value": 0.2}, {"label": "t-02", "value": 0.45}, {"label": "t-03", "value": 0.4}, {"label": "t-04", "value": 0.68}, {"label": "t-05", "value": 0.62}, {"label": "t-06", "value": 0.81}, {"label": "t-07", "value": 0.77}, {"label": "t-08", "value": 0.9}]
```
