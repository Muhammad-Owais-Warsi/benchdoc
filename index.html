Single-file · Offline · Themed

benchdoc

Turn a Markdown file into one clean, self-contained HTML report you can share as a file.

quickstart
# 1 · Install
npm install -g benchdoc

# 2 · Scaffold a starter report
benchdoc init
Wrote report.md

# 3 · Render it to a single HTML file
benchdoc report.md -t docs
Wrote report.html

One file out

CSS, fonts, images and scripts are inlined. Attach it, email it, drop it anywhere.

Works offline

No CDN, no build step, no account. Opens anywhere a browser does.
